# 💰 사회초년생의 자산 관리 시뮬레이션 (Asset Management Sim)

![Game_Main_Screen](https://github.com/user-attachments/assets/1c53e947-1795-484d-a4dc-41bad8d34bba)

> **"10개월의 시간, 당신은 얼마나 많은 자산을 모을 수 있습니까?"** > 사회초년생이 되어 월급 관리, 자기계발, 금융 활동을 통해 최고의 자산가에 도전해보세요!

---

## 🎮 게임 조작 방법 (Controls)

* **이동**: 키보드 방향키 ($\uparrow, \downarrow, \leftarrow, \rightarrow$)를 사용하여 캐릭터를 조작합니다.
* **상호작용**: 각 건물의 입구(노란색 화살표)로 이동하면 전용 UI 패널이 활성화됩니다.
* **선택**: 마우스 클릭을 통해 퀴즈 정답 선택 및 금융 활동을 수행합니다.

## 🕹️ 전체적인 게임 진행 (Gameplay)

1. **자산 극대화**: 매달 들어오는 월급으로 적금을 들거나, 아카데미에 투자하여 기본급 자체를 높여야 합니다.
2. **리스크 관리**: 매달 발생하는 **생활비(100만 원)**와 **대출 이자**를 고려하여 현금 잔고를 관리하세요.
3. **경제 퀴즈**: 한 달에 한 번 퀴즈에 참여할 수 있으며, 정답 시 **10만 원**의 보너스를 획득합니다.
4. **돌발 이벤트**: 길을 건널 때 발생할 수 있는 **교통사고**는 자산과 스트레스에 큰 타격을 줍니다.

---

## 🏆 엔딩 및 스코어 (Ending & Score)

10개월이 경과하면 게임이 종료되며, 최종 자산에 따라 점수가 결정됩니다.

### **스코어 계산 방식**
$$최종 점수 = 현재 현금 + 적금 총액 - 남은 대출 원금$$

### **엔딩 종류**
* **🎉 성공 (Success)**: 10개월을 무사히 마치고 최종 자산을 정산받는 경우.
* **💸 파산 (Bankrupt)**: 보유 현금이 0원 미만이 되어 경제 활동이 불가능해진 경우.
* **😫 과로 (Burnout)**: 스트레스가 100%에 도달하여 건강 문제로 게임이 중단된 경우.
